## DEFECTS FOUND
D-P3-1  [HIGH/BLOCKER if cost privacy is a contract term] Staff UI shows cost price: /products/detail as staff shows "ক্রয়মূল্য ৳ ১০০.৫০" (screens/p3-375-staff-sees-cost-price.png).
        Root cause proven at API: staff GET /v1/sync/pull returned events with costPoisha (containsCostPoisha=true) although REST /v1/products hides it. (Same as KNOWN_LIMITATIONS B1 / security H1.)
D-P3-2  [MEDIUM] Expired stock on hand is invisible on the home "নজর দিন" panel and in the stock-page "মেয়াদ কাছে" count: with a 5-pc batch expired in 2020, home says "এখন সব ঠিক আছে।" and filter shows 0.
        Cause: lib/store/selectors.ts:84-86 expiringSoonCount() returns only expiryBuckets().within30; the `expired` bucket is never counted. The /stock/expiry page itself does list it.
D-P3-3  [LOW] ASCII digits inside the Bangla UI: pay page "পণ্যের সংখ্যা 1টি" (and other counts) and the stock error "স্টকে মাত্র 10 পিস আছে". (CLAUDE.md says Bangla digits everywhere.)
D-P3-4  [MEDIUM] Hold/resume bills is NOT built: /sell has scan, search, cart and "বিল খালি করুন" only; one draft cart. PRD P0 asks for multiple concurrent carts.
D-P3-5  [LOW] Staff bottom nav still shows "রিপোর্ট" which then says owner-only (works safely, confusing UX).
D-P3-6  [LOW] Cart lets qty exceed sellable stock (13 vs 10); the block only happens at payment. Hint is shown.
D-P3-7  [INFO] Stock-in accepts an already-expired expiry date (01/2020) without warning (it is flagged expired afterwards).
