## HIGH
H1  Staff can read cost price via sync pull (confirms KNOWN_LIMITATIONS B1).
    server/app.ts:251-259, src/db/pg.ts:149-165: pull returns raw `payload` for any authenticated user, no role filter.
    REST path hides cost correctly (src/domain/product.ts:157-158). Staff GET /v1/sync/pull?after=0 returns product_upserted/stock_in with cost + owner events.
H2  Sync event bodies not validated server-side (confirms B7).
    server/app.ts:53-67 checks envelope only (id, kind, at, object payload, <=32KB). A staff token can push sale_completed/stock_in/due_received/product_upserted with arbitrary content
    (zero-price sale, negative qty, back-dated `at`, fake due payment). All owner devices replay them.

M2  Audit trail partial: no read-access log, no staff create/deactivate log, no login history; auth_attempts purged after 1 day; no customer erase path.

M7  sync_events has no quota/expiry; 100 events/push x 600 req/min/store x 32KB cap -> one cheap account can fill the DB disk for all tenants (A6).
